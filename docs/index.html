NFC 蓝牙灯遥控器
工作流程 怎么使用 标签说明 项目文件

ESP32-S3 · NFC · 蓝牙灯控

碰一下标签，再按按钮开关灯

遥控器读取 NFC 标签里的灯具资料，通过蓝牙连接灯板。连接成功后，按一下遥控器上的按钮就能切换灯的开关状态。

01

它是怎样工作的？

标签负责告诉遥控器要连接哪盏灯；连接后，按钮负责开关灯。

1. 靠近标签

遥控器读出标签里保存的灯具资料。

2. 连接蓝牙灯

遥控器按标签里的资料找到灯并建立连接。

3. 连接准备好

遥控器亮绿灯，表示可以控制灯了。

4. 按键控制

按 GPIO9 按钮，灯就在亮与灭之间切换。

02

怎么使用？

写标签只需做一次。写好后，日常使用只要碰一下标签并按按钮。

第一次：写入空白标签

  1. 打开灯板和遥控器。
  2. 按住遥控器 GPIO9 按钮约 5 秒，看到蓝灯后松开。
  3. 把一张空白 NTAG 标签贴近读卡器，并保持不动。
  4. 写入检查成功后，遥控器会自动重启。

已经写过内容的标签不会被覆盖。平时开机不会自动写卡。

平时：连接并控制灯

  1. 打开灯板和遥控器。
  2. 把写好的标签贴近遥控器读卡器。
  3. 等遥控器亮绿灯，再移开标签。
  4. 按一下 GPIO9 按钮切换灯的开关状态。

同一张标签要先移开，再重新靠近，遥控器才会再次读取。

03

遥控器上的颜色代表什么？

看遥控器的 RGB 灯，就能知道当前进度。

绿灯已连接，按键可以控制灯。
红灯首次读卡或连接没有成功；移开标签后再试。
蓝灯正在等待空白标签写入。
04

标签里保存了什么？

标签里保存的是连接灯所需的资料，不是开关命令。

  • 灯的名称和蓝牙地址，帮助遥控器找到正确的灯。
  • 首次连接时要用的配对资料。
  • 不是靠标签的卡号来配对或控制灯。
  • 以后连接要用的长期资料保存在遥控器和灯板里，不写在标签上。
05

安全提醒

当前配置用于项目演示和开发测试。

不要把这套演示配置用于门锁或重要设备

当前遥控器和灯使用相同的固定配对资料，而且标签内容可以被读取和复制。别人复制标签后，也可能拿到连接所需的资料。

06

想多了解一点？

下面是可选阅读内容，日常使用不需要了解这些名词。

配对时的随机数从哪里来？

遥控器和灯板会各自产生一个随机数，并在首次连接时互相交换、核对。随机数不会预先写在 NFC 标签里。

TK、STK、LTK 是什么？
  • TK：首次配对时双方共同使用的资料；当前演示版本的设备共用同一份。
  • STK：首次配对过程中临时生成的加密钥匙，只用于建立这次连接；不存放在标签里。
  • LTK：首次连接后保存到两块板里的长期钥匙，之后重新连接时使用；不存放在标签里。
硬件接线

PN532：SDA 接 GPIO4，SCL 接 GPIO5，IRQ 接 GPIO6，RESET 接 GPIO7。遥控器按钮接 GPIO9，遥控器和灯板的 RGB 灯接 GPIO48。

07

项目文件在哪里？

这些链接打开的是程序源代码。只想使用遥控器的话，不需要打开它们。

  • 遥控器的读卡流程ntag_read.c：识别标签、等待写卡或发起连接。
  • 标签内容的读写nfc_ble_oob.c：把连接资料写进标签，并在使用时读出来。
  • 遥控器的蓝牙和按键remote_ble.c：连接灯、处理 GPIO9 按钮和更新状态灯。
  • 灯板的蓝牙和灯光ble_lamp.c：接收遥控命令并控制 RGB 灯。
  • 两块板共用的设置ble_oob_config.h：保存设备名称和开发测试用的配对资料。
本页根据项目当前固件整理。若连接失败，请先确认灯板已上电，再移开标签并重新靠近读卡器。
